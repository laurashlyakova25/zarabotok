# Мой заработок

Личное приложение для учёта смен, праздничных часов, апселлов и зарплаты по половинам месяца.

- **Интерфейс** — эта страница на GitHub Pages: устанавливается на iPhone как приложение со своей иконкой.
- **Данные** — в вашей Google Таблице, серверная логика — Google Apps Script (`apps-script/Code.gs`).
- **Доступ** — по секретному ключу. Ключа нет в этом репозитории, он вводится один раз на каждом устройстве. Код открыт, данные — нет.

---

## Шаг 1. Обновить Apps Script (5 минут)

Работаем в уже существующем проекте Apps Script, привязанном к таблице «Мой заработок». Данные в таблице не меняются.

1. Откройте таблицу → **Расширения → Apps Script**.
2. Файл **«Код»**: выделите всё (Cmd+A) и вставьте содержимое `apps-script/Code.gs`. Сохраните.
3. Файл **appsscript.json**: замените содержимым `apps-script/appsscript.json`. Сохраните. Файл `Index` больше не нужен — его можно удалить.
4. Вверху выберите функцию **createApiKey** → **Выполнить**. Если Google попросит разрешения — разрешите.
5. Внизу откроется **Журнал выполнения** со строкой `Ключ доступа: …`. Скопируйте ключ и сохраните, например, в «Заметки» с паролем или в «Пароли» на iPhone.
6. **Начать развертывание → Управление развертываниями → карандаш**:
   - Версия: **Новая версия**;
   - У кого есть доступ: **Все**;
   - **Развернуть**. Адрес `/exec` остаётся прежним — скопируйте его.

«Все» означает, что адрес отвечает без входа в Google, но без ключа сервер не выдаёт и не принимает никаких данных.

## Шаг 2. Выложить приложение на GitHub (5 минут)

1. Войдите на github.com → **New repository**. Имя, например, `zarabotok`. Видимость **Public** (на бесплатном тарифе GitHub Pages работает только для публичных репозиториев). → **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**. Перетащите все файлы: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, пять картинок `*.png` и папку `apps-script` (файл `.nojekyll` не обязателен). → **Commit changes**.
3. **Settings → Pages**: Source — **Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты вверху страницы Pages появится адрес вида `https://<ваш-логин>.github.io/zarabotok/`.

## Шаг 3. Установить на iPhone

1. Откройте адрес из шага 2 в **Safari**.
2. **Поделиться → На экран «Домой» → Добавить**. На главном экране появится иконка «Заработок».
3. Откройте приложение с иконки. Оно запустится на весь экран, без панели Safari.
4. На экране «Подключите устройство» вставьте адрес `/exec` и ключ → **Подключить**.

На MacBook откройте тот же адрес в браузере и подключите так же. В Safari на Mac можно добавить его в Dock: **Файл → Добавить в Dock**.

## Обновления

Когда я пришлю новую версию, загрузите изменённые файлы в репозиторий (**Add file → Upload files**, с заменой). Приложение на iPhone обновится само при следующем запуске с интернетом. Если меняется `apps-script/Code.gs`, его нужно заменить и в Apps Script и сделать **Новую версию** развертывания.

## Если что-то случилось

- **Потеряли телефон или ключ стал известен кому-то** → в Apps Script выполните `rotateApiKey`. Старый ключ сразу перестанет работать, новый будет в журнале. Введите его заново на своих устройствах.
- **«Ключ не подошёл»** → скопируйте ключ ещё раз из журнала `createApiKey` (функция показывает текущий ключ, не меняя его).
- **«Нет связи с сервером»** → проверьте, что адрес оканчивается на `/exec` и что в развертывании выбран доступ **Все**.
- **Отключить устройство** → «Настройки» → «Хранение и безопасность» → «Отключить это устройство».
